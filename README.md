# SinfonIA Castlevânica Futurística · SNES

Projeto homebrew de ação e exploração para Super Nintendo, desenvolvido para Maicon Lino.

## Organização da revisão

Este repositório está recebendo o código-fonte, os assets autorais, a ROM e os testes da adaptação nativa. A versão original será preservada antes das alterações de movimento, animação e portas.

- Plataforma: SNES, CPU 65C816 e áudio SPC700.
- Formatos de distribuição: `.smc` e `.sfc`.
- Compilação: Python 3, ca65 e ld65.
- A versão de navegador é um projeto separado.

## Escopo da revisão solicitada

Corrigir a repetição das partes das portas, melhorar a resposta e a continuidade do movimento, ampliar as animações e melhorar a leitura visual sem mudar artificialmente a plataforma-alvo. As alterações devem ser acompanhadas por testes e notas que distingam o que foi verificado do que ainda depende de teste humano.

Projeto independente, sem afiliação com Nintendo ou Konami. Não inclui ROMs comerciais.
